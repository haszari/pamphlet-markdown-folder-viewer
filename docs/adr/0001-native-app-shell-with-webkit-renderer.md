# Use a native macOS app shell with a WebKit renderer

The app uses a native SwiftUI/AppKit shell for macOS chrome, windows, menus, file opening, Finder integration, and packaging, while a separate WebKit renderer handles markdown, code, image, table rendering, link classification, and content themes. This keeps the app feeling native where macOS behaviour matters, while using the web platform and a Vite/TypeScript renderer package for rich, themeable read-only content. Built renderer assets are generated by the full-stack build rather than committed, so the renderer source remains the source of truth.
